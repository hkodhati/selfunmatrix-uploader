SelfUnMatrix Uploader

Privacy Policy · Terms of Service

A personal tool that uploads lesson videos to the owner's own YouTube channel, !SelfUnMatrix!. It is not offered to other users.

This tool uses YouTube API Services.

Privacy policy

The uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

The uploader uses Google sign-in only to upload videos and read basic details of the channel that signed in (to confirm it is the right channel). It requests the YouTube scopes youtube.upload and youtube.readonly.

What is accessed, stored and shared

  • Accessed: the signed-in channel's ID and title, and the videos the tool itself uploads.
  • Stored: only an OAuth token and the IDs of videos the tool uploaded, kept in files on the owner's own computer. Nothing is stored on any server.
  • Shared: nothing. No data is sent anywhere except Google's own APIs, and none is sold or used for advertising.
  • It does not collect data about any other person, viewer or account, and it uses no cookies or tracking.

Deleting your data and revoking access

Access can be revoked at any time at Google security settings. Deleting the local token.json and state.json files removes all stored data immediately. Revoking access in Google's settings stops the tool from making any further requests.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
